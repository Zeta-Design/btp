# Docs

Source-graded research, decisions, and plans for the business. Most of this is produced by the
`researching-photography-business` skill (`.claude/skills/`). Every doc is dated, traces its claims
to graded sources, and opens with a plain-language TL;DR.

**Folder lifecycle:** `research/` (thinking that informs us) → `decisions/` (choices we commit to) →
`plans/` (what we'll actually do).

## Conventions
- **Research note** → `research/<topic>.md` — options weighed against the Principle Lens; "research
  only" unless it feeds a decision.
- **Decision record** → `decisions/NNNN-<slug>.md` — one lasting choice, with all its consequences.
- **Plan / SOP** → `plans/<thing>.md` — a measurable plan for something we'll do, with a Definition of Done.
- Anything touching contracts, copyright, or taxes flags the **legal/tax line** and points to a pro —
  these docs research and inform; they are not legal or tax advice.
